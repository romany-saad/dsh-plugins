# Changelog

## 0.1.1

- **An icon.** DSH's Plugins page now shows the plugin's own icon instead of the default artwork, in the light and dark themes. Nothing else changes.

## 0.1.0

- **Unsent drafts above a new conversation.** A message you typed into a new conversation and left before sending is listed above the message box of the next new conversation, with **Open** to go back to it and **Discard** to drop it (with **Undo**).
